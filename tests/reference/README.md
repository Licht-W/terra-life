# TL-M1-001 乱数の固定参照値

`random-vectors.json`は本番TypeScriptを呼ばず、著者のC参照実装を既存のClang 20.1.2（x86_64-w64-windows-gnu）で実行して生成した固定値です。VitestはJSONを読むだけで、生成・更新を行いません。通常のテストにCコンパイラは不要です。

| [splitmix64.c](https://prng.di.unimi.it/splitmix64.c) | `071795A8E29978A5CBD7015CE8F7D772E7AB4631E574E9102B748FE99105FF3D` | 任意64bitシードから連続2出力 |

`generate-fixture.ps1`は先にこのハッシュを照合します。xoshiroのソースは「This is the long-jump function」のコメント直前までを一時的なコンパイル入力へ抽出し、next・jumpだけを利用します。vendor原本は編集しません。long-jump・任意距離jumpとその追加依存は対象外です。SplitMix64のnextだけをプリプロセッサでsplitmix64_nextへ改名し、両参照実装を同じハーネスから呼びます。著者の状態遷移・出力演算・jump定数は変更しません。

再生成が必要な場合は、プロジェクトルートで実行します。既存のC11コンパイラを使用し、グローバル導入・実行ポリシー変更は行いません。

```powershell
& ./tests/reference/generate-fixture.ps1
# コンパイラのパスを明示する場合：
& ./tests/reference/generate-fixture.ps1 -Compiler C:/llvm-mingw-x86_64/bin/clang.exe
```

実際のビルドは`-std=c11 -Wall -Wextra -Wno-sign-compare -Werror`でコンパイルし、別工程でリンクします。著者コードの符号付きループ変数とsizeofの比較だけを警告除外しています。一時オブジェクトと実行ファイルは`.npm-cache/tl-m1-001-reference`内です。最初の一括コンパイルはsandbox内TEMPのrenameで拒否されたため、オブジェクト出力をプロジェクト内へ明示した2工程にしました。PC設定は変更していません。

ハーネスは各seedでSplitMix64の2出力を16桁hexとして記録し、各出力を下位→上位32bitの順で並べます。元状態をlife、jump1回をflavor、jump2回をbirthに対応付けます。これはTL-M1-001第3章の割当をC側で組み立てる処理です。

| 検証値 | 用途と理由 | 見直し条件 |
| --- | --- | --- |
| seed `0000000000000000`、`0000000000000001` | 正当な0シード、最小差と低位bit | 初期化契約が明示的に変更された場合 |
| seed `ffffffffffffffff`、`8000000000000000` | 64bit加算の桁あふれ、最高位bit・符号扱い | 同上 |
| seed `0123456789abcdef`、`deadbeefcafebabe` | 多様なbit配置と混合 | 追加の演算不具合が見つかったらケースを追加 |
| 状態 `[1,2,3,4]` | s[0]／s[1]取り違え・通常遷移 | 追加の演算不具合が見つかったらケースを追加 |
| 状態 `[4294967295,4294967295,4294967295,4294967295]` | uint32乗算・シフト・回転・符号なし化 | 同上 |
| 状態 `[0,0,0,2147483648]` | 非全0だがゼロワードを含む状態、最高位bit | 同上 |
| 状態 `[2147483648,4294967295,0,1]` | 高位bit・最大値・0の混在 | 同上 |
| 各状態から連続12出力と各直後状態 | 初期化6seed×3系列、直接状態4件×元／jump／2回jump、計360遷移を照合 | 不具合により追加の列長が必要な場合 |
| 各系列の追加17消費・残り2系列の後続12出力 | 出生・人生結果・フレーバー各系列の消費が他系列を変えないこと | 消費API・系列構造を変更する場合 |
| 交互30呼出し・11呼出し後にJSON／コピー再開 | 出生・人生結果・フレーバーの異なる途中位置から再開 | 呼出しAPI・状態表現を変更する場合 |
| 変換入力0、1、2147483648、4294967295 | `u32 / 2^32`の下端・最小刻み・高位bit・1未満の上端 | 変換契約が明示的に変更された場合 |
